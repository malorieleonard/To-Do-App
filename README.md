# To-Do List Application

A Java desktop application developed as a four-person team project. The
application allows users to create, organize, prioritize, and complete
personal, business, and educational tasks through a graphical interface.

## Features

- Create personal, business, and educational tasks
- Assign task names, descriptions, due dates, and priority rankings
- Mark tasks as complete
- Organize tasks by category
- Graphical user interface for creating and managing tasks

## Technologies & Concepts

- Java
- Object-Oriented Programming
- Inheritance and Interfaces
- MVC-style application structure
- Unit Testing
- Git / GitHub
- Scene Builder
